# Logo Checkpoint

La **C** aperta inquadra un rombo: il punto in cui il giocatore salva una tappa della propria esperienza. L'header accosta il simbolo al nome `checkpoint`.

- [`src/app/icon.svg`](../../src/app/icon.svg) è il simbolo vettoriale usato nell'header e dal browser come icona del sito.
- `checkpoint-brandkit.png` conserva la tavola di presentazione del marchio.

Le copertine e le schermate nella tavola sono mockup, non schermate o dati effettivi dell'app.
